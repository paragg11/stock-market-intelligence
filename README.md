
# AI-Powered Stock Market Research & Investment Intelligence Platform

## Project Overview

An end-to-end quantitative finance and AI project designed to analyze Indian stock market data, predict market direction, forecast financial risk, optimize portfolios, and generate explainable investment research.

## Project Objectives

- Analyze six years of historical NSE stock data.
- Engineer technical indicators.
- Predict next-session stock market direction using Machine Learning.
- Apply Explainable AI using SHAP.
- Develop neural network models.
- Forecast returns and volatility.
- Optimize investment portfolios.
- Build an investor-profile-based recommendation engine.
- Develop an eight-agent AI research workflow.
- Deploy an interactive Streamlit dashboard.

## Technology Stack

- Python
- Pandas and NumPy
- Yahoo Finance API (yfinance)
- Scikit-learn and XGBoost
- TensorFlow
- SHAP
- ARIMA and GARCH
- LangChain and LangGraph
- FastAPI
- Streamlit
